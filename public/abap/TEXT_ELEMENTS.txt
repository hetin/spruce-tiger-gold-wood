ZMM_MAT_MASTER_RPT — Text Elements
===================================
After pasting the program in SE38 / SE80:

1) Goto → Text Elements → Selection Texts  (or run the program once:
   INITIALIZATION already fills selection labels via %_..._%_APP_%-TEXT)

2) Goto → Text Elements → Text Symbols
   Click "Compare Text Symbols from Program" then Save/Activate.

   If compare is empty, create these symbols manually:

   001  Comprehensive Material Master Report
   002  Double-click material to open MM03
   003  Rows selected
   004  Rows skipped (authorization)
   005  Text read errors (ignored)
